# Top Gear 2 — SNES Native Recompilation (WIP)

> [!NOTE]
> This project is currently a **work in progress**. Build and setup automation are still under development.

An experimental native C port of **Top Gear 2** (SNES, 1993) built through W65C816 static recompilation.

## Features

- Native 16:9 widescreen and 4:3 aspect ratio toggle (`F4`)
- Visual modes: Pixel Puro (`F1`), CRT Arcade (`F2`), and Enhanced HD (`F3`)
- Authentic SPC700 + DSP stereo audio
- 2-player local & gamepad support with an in-game `ESC` settings menu
- Car paint customization and Save States (`F5` / `F8`)

## Requirements

- A legally obtained copy of **Top Gear 2 (USA)** (`.sfc` or `.smc`)
- **SDL2** runtime library
